# Homebrew tap for apple-notes-tui

This tap provides the Homebrew formula for [apple-notes-tui](https://github.com/dmshvedchenko/apple-notes-tui), a keyboard-first terminal UI for Apple Notes.

## Install

```bash
brew install dmshvedchenko/tui-notes/apple-notes-tui
```

Or add the tap first:

```bash
brew tap dmshvedchenko/tui-notes
brew install dmshvedchenko/tui-notes/apple-notes-tui
```

## Use

```bash
apple-notes-tui
```

Check the installed version:

```bash
apple-notes-tui --version
```

The v0.1.0 prebuilt Homebrew artifact supports Apple Silicon / arm64 macOS.
